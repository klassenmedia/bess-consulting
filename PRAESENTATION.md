# Seite Waldemar zeigen

## Adresse

Solange der Server läuft:

    http://localhost:4321

Im selben WLAN auch von Handy oder Tablet erreichbar:

    http://192.168.2.132:4321

Die zweite Adresse ist praktisch, um Waldemar die Seite direkt auf dem Handy
zu zeigen. Sie funktioniert nur im gleichen Netz.

## Server starten

Im Ordner ~/bess-consulting:

    npm run dev

## Server stoppen

    astro dev stop

## Läuft er noch?

    astro dev status

## Wenn Port 4321 belegt ist

    npm run dev -- --port 4322

## Was Waldemar sehen wird

Startseite mit der neuen Positionierung „Nicht noch ein Bericht. Sondern das
Ergebnis.", zwei Angebote (Quickcheck ab 2.500 €, Kernprodukt ca. 8.500 € mit
48 Monaten Begleitung), Multi-Site-Verfahren, Rechner, 17 FAQs, Terminbuchung,
Wissensbereich mit drei Artikeln.
